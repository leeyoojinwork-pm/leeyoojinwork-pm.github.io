03 / AI CONTENT WORKFLOW

AI로 만드는 것에서,
품질을 관리하며 만드는 것으로.

문제
다국어 AI 아바타 강의는 번역만 맞아도 완성되지 않습니다. 음성, 립싱크, 자막의 품질을 함께 확인해야 했습니다.
판단
도구별 결과를 따로 검토하지 않고 제작 단계마다 확인할 항목과 수정 경로가 이어지도록 구성했습니다.
실행
강의 원문부터 번역, 음성, 아바타 영상까지 제작 흐름과 QA 기준을 설계했습니다. 제 역할은 전체 콘텐츠의 단독 제작이 아닌 제작 프로세스와 검수 운영이었습니다.

HOW I WORK

AI를 어디에 쓸지보다,
어떤 문제를 풀지 먼저 묻습니다.

01 / DEFINE

현업의 문제를 좁힙니다

막연한 불편을 사용자와 담당자가 실제로 멈추는 장면으로 좁힙니다. 요구 기능보다 현재 업무와 제약을 먼저 확인합니다.

02 / DECIDE

기준과 예외를 설계합니다

정상 경로뿐 아니라 권한이 없을 때, 결제가 실패할 때, AI 결과를 수정해야 할 때의 처리 기준까지 구체화합니다.

03 / VERIFY

완료의 기준을 끝까지 봅니다

응답 생성이나 결제 성공을 완료로 보지 않습니다. 사람이 결과를 쓰고 다음 업무를 이어갈 수 있는지 검증합니다.
